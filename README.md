# U.S. Population and Migration Patterns

## Purpose
This project analyses internal and external migration trends across the United States to inform business strategy and policy. We examine which states attract or lose residents and how international migration influences state economies.

## Data
- **U.S. Census Bureau** population and migration datasets (domestic and international).
- Economic indicators (employment, income) by state.

## Analysis
- **Map visualisations** of net migration flows between states.
- **Trend analysis** of population change over time.
- **Regression models** linking migration patterns to economic variables.

## Findings
Southern states attract the largest share of foreign immigrants, while some regions experience sustained domestic out-migration. The results help companies and policymakers understand demographic shifts.

## How to Use
Clone the repository, install dependencies with `pip install -r requirements.txt` and run the Jupyter notebook in the `analysis/` directory to reproduce the charts and models.
